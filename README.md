# Valmeto Tool

İş seyahati için Kahire ve çevresindeki alüminyum ve bakır fabrikalarının listesi (iletişim + ürünler), harita ve ziyaret notu aracı.

- `index.html` – liste, arama/filtre, ziyaret notları, fiyat kaydı, CSV
- `musteriler.html` – Türkiye & Balkanlar potansiyel müşteriler (ülkelere göre, takip/CRM)
- `harita.html` – Leaflet/OpenStreetMap haritası (Mısır üreticileri + müşteriler)
- `data.js` / `musteriler.js` – veriler (yeni firma eklemek için burayı düzenleyin)
