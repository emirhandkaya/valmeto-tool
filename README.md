# Kahire Alüminyum & Bakır Fabrika Rehberi

İş seyahati için Kahire ve çevresindeki alüminyum ve bakır fabrikalarının listesi (iletişim + ürünler), harita ve ziyaret notu aracı.

- `index.html` – liste, arama/filtre, ziyaret notları, fiyat kaydı, CSV
- `harita.html` – Leaflet/OpenStreetMap haritası
- `data.js` – fabrika verileri (yeni firma eklemek için burayı düzenleyin)

Yayın: GitHub Pages → https://emirhandkaya.github.io/Egypt-fabrics/
